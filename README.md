1. **AMD EPYC 是底层硬件平台。**
2. **套餐名称和配置仍然按 BandwagonHost 的 VPS 产品页面展示。**

## AMD VPS 购买时应该确认什么

购买 BandwagonHost AMD VPS 时，建议按下面的顺序检查。

### 先确认地区，而不是只看套餐名

同一个 80G 或 160G 套餐，放在不同地区，访问延迟、线路和底层硬件可能不同。提供的 AFF 链接会跳转到洛杉矶 DC9 订购路径，但具体可购买的规格和库存仍要以页面实际显示为准。

如果页面允许选择数据中心，先确定用户所在区域，再看 AMD 节点是否可用。

### 确认 CPU 信息是否写在订单页

官方新闻确认某些地点已经部署 EPYC，但这不等于所有时段、所有规格都能手动锁定 AMD。购买前应查看：

- 节点名称
- CPU 型号
- 是否标注 AMD EPYC
- 存储是否为 NVMe
- 是否存在“新硬件”或升级选项
- 订单确认页是否保留这些配置

如果订单页面只显示通用 VPS 规格，没有明确 CPU 型号，就应该把它理解为“该地区可能运行在 AMD 新节点上”，而不是“购买后必然获得指定 EPYC 型号”。

### 确认是否需要预付

20G 和 40G 的低价分别对应年付和半年付。低月均价格的前提是提前支付较长周期费用。

如果你只是短期测试 AMD VPS，80G 月付虽然标价更高，但更容易控制试用成本。等确认性能、线路和应用兼容性后，再考虑长期预付。

### 确认是否接受自管理模式

BandwagonHost 的价格建立在自管理模式上。官方提供基础设施和网络层面的服务，但应用部署、Linux 配置、数据库调优、网站迁移、恶意软件清理和安全加固通常需要用户自己完成。

以下用户更适合这种模式：

- 熟悉 SSH 和 Linux 命令行
- 能独立处理防火墙和系统更新
- 会配置备份
- 能定位应用层故障
- 希望自己控制系统环境

如果你需要客服帮忙安装程序、修复代码或调试数据库，那么“AMD EPYC”本身无法解决运维需求。
